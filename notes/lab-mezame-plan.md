# 特別編「めざめの3秒 — ぜんぶ同時に見る」設計書

2026-07-28 着工。v3-07「めざめの3秒」の完全版。エンジン始動の数秒間を、
弁・回転数・圧力・温度・吸込余裕が「ぜんぶ同時に動く」1本のフィルムとして見せる。

## 事実忠実ルールとの折り合い（最重要）

- 主役は**架空の教材エンジン「あさひ」**。実在エンジンの始動シーケンス（特にLE-9）は
  非公開情報が多く、実名で秒単位の波形を描くと捏造になるため。
- ページ冒頭に「教材用の模式エンジン」であることを明記する。
- 物理の**形**（因果の連鎖・波形の定性形状）は公開文献と整合させる:
  チルダウン→タンクヘッドの微小流→点火→壁加熱→ブートストラップ自励→主段化。
- 数値は教材用の丸めた値で、実在機のどれとも一致させない。
- 出典欄に実在の公開資料（SSME始動シーケンス、RL10チルダウン、LE-5B系の
  アイドルモード燃焼・自己始動の公開論文）を並べ、「本物への橋」とする。

## 教材エンジン「あさひ」憲法

- 液体水素/液体酸素、**エキスパンダーブリードサイクル**（LE-5B系の血筋という設定）
- 真空推力 300 kN級 ／ 燃焼室圧 6.0 MPa ／ 定格混合比 5.5
- FTP 45,000 rpm ／ OTP 16,500 rpm（別軸・タービン直列ブリード）
- 始動方式: タンクヘッドスタート（自己始動）。外部ガス供給なし
- 冷却: 燃焼室再生冷却。ジャケットで温まった水素の一部(~15%)がタービンを回して排出

## 始動シーケンス（ノミナル「きほんの朝」）

| t[s] | できごと |
|---|---|
| -0.5〜0 | 静けさ。チルダウン完了、配管は極低温 |
| 0.0 | MFV開（0.3sでランプ）。タンクヘッドの水素が流れ、無点火のまま〜5,000rpm台までそっと回る |
| 0.5 | 点火器作動 |
| 0.8 | MOV 20%へ |
| 1.0 | 点火。小さな火が壁を温め始める（燃料リッチ、混合比は薄い側から登る） |
| 1.5〜3.8 | ブートストラップ: 回る→流れる→温まる→もっと回る（S字加速） |
| 2.2〜2.6 | MOV 100%へ |
| N>38,000 | TCV（回転数連動の弁スケジュール）がブリードを絞る |
| ~4.2 | 主段化入り（点火から約3秒 = タイトル回収。定格の約9割） |
| 〜5.0 | 整定（pc 5.9MPa・288kN・MR5.5）。吸込余裕比は追加加圧が済むまで1.7へ細りながら整定 |

## 簡約モデル（事前計算・集中定数系・Euler 50Hz）

状態量: N(FTP rpm), Nox(OTP rpm), Twall(壁温K), pc(室圧MPa)

v2（2026-07-28 Codex物理レビュー反映後）:

- **エネルギー収支を閉じた**: 燃料 12 kg/s・酸素 56.5 kg/s・MR 5.5・推力 ~290kN（Isp≈450s級で整合）。
  ポンプ水力 P_p = ṁΔp/(ρη) ≈ 12×8.7MPa/(70×0.65) ≈ 2.3MW。
  タービン: ブリード1.73kg/s × ~1.3MJ/kg（H2・圧力比~10・η~0.65級）≈ 2.3MW で釣り合う
- 燃料流量 mdot_f = MFV × (1.2 + 10.8·N/45000) × (1−α)（αはポンプ入口ボイド率、チル不足のみ>0）
- **ブリードは質量保存**: mdot_bleed = 0.2·TCV·mdot_f、室へは mdot_core = mdot_f − mdot_bleed
- ジャケット出口温度 Th = 50 + (Twall−50)·w, w = 0.85/(1+mdot_f/6)
- **駆動立ち上がり係数** drv = 0.25 + 0.75·(N/45000)^1.5 — タンク圧起点の有限圧力比+低速タービン
  マップ+立ち上がり損をまとめた教材係数（「圧力比が取れない」という誤説明を廃止）
- タービン出力 P_t = kt × mdot_bleed × (Th−45) × drv、kt=9,180（実効仕事 ~1.3MJ/kg相当）
- dN/dt = kN·(P_t−P_p)/(N+2000)、kN=700（回転力学の教材近似であることを明記）
- OTP: Nox は駆動力追従の一次遅れ Nox_cmd = 16500×clamp(P_t/2.3MW)（FTP回転数への直接従属を廃止）
- 酸素流量 mdot_o = MOV × (2.5 + 54.0·Nox/16500)（定格56.5kg/s）
- 点火後 pc → 0.0898×(mdot_core + mdot_o)×η（η: 0.6→1.0）、推力 F = 49·pc（**点火前はF=0**）
- 壁温: 点火前は水素で徐冷(→90K)、点火後 dTwall/dt = 1.6·((150+450·pc/(pc+0.8)) − Twall)
  （壁温は冷却側実効金属節点。一般の燃焼室壁温ではない）
- 酸素側吸込余裕比 = NPSHa/NPSHr（NPSHrは規定ヘッド低下基準の教材値。比1.0は絶対境界ではない）。
  NPSHa 50→75m は始動シーケンスの追加加圧（初期タンク圧は始動に足りている前提）。
  ノミナルは1.7へ細りながら整定（「谷から回復」とは言わない）

### 外乱3本の実装（v2）

- **chill**: ポンプ入口ボイド率 α₀=0.55、冷流で徐々に回復（dα/dt=−0.10·α·(0.3+mdot_f)）。
  壁温は正常（チル不足の本体はポンプ入口という物理に修正）。所定時刻(3.0s)の室圧不足でレッドライン中止。
  停止時の弁順序・時刻は演出（ページに非実務注記）
- **tank**: NPSHa 33→57m（加圧3.6〜4.8s）。余裕比<1.25で流量低下+4Hz変調
  （**様式化した信号演出**と明記。キャビティ力学の予測ではない）。谷1.22→回復1.31
- **ign**: 点火1.8s遅れ。ハードスタートは正の圧力パルス+減衰リップルを記録値に乗せる
  **合成の危険演出**（モデル予測ではない。「遅れは危険を生む」という因果で語る）
