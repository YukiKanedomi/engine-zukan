# 特別編「めざめの3秒 — ぜんぶ同時に見る」設計書

2026-07-28 着工。v3-07「めざめの3秒」の完全版。エンジン始動の数秒間を、
弁・回転数・圧力・温度・吸込余裕が「ぜんぶ同時に動く」1本のフィルムとして見せる。

## 事実忠実ルールとの折り合い（最重要）

- 主役は**架空の教材エンジン「あさひ」**。実在エンジンの始動シーケンス（特にLE-9）は
  非公開情報が多く、実名で秒単位の波形を描くと捏造になるため。
- ページ冒頭に「教材用の模式エンジン」であることを明記する。
- 物理の**形**（因果の連鎖・波形の定性形状）は公開文献と整合させる:
  チルダウン→タンクヘッドの微小流→点火→壁加熱→ブートストラップ自励→主段化。
- 数値は教材用の丸めた値で、実在機のどれとも一致させない。
- 出典欄に実在の公開資料（SSME始動シーケンス、RL10チルダウン、LE-5B系の
  アイドルモード燃焼・自己始動の公開論文）を並べ、「本物への橋」とする。

## 教材エンジン「あさひ」憲法

- 液体水素/液体酸素、**エキスパンダーブリードサイクル**（LE-5B系の血筋という設定）
- 真空推力 300 kN級 ／ 燃焼室圧 6.0 MPa ／ 定格混合比 5.5
- FTP 45,000 rpm ／ OTP 16,500 rpm（別軸・タービン直列ブリード）
- 始動方式: タンクヘッドスタート（自己始動）。外部ガス供給なし
- 冷却: 燃焼室再生冷却。ジャケットで温まった水素の一部(~15%)がタービンを回して排出

## 始動シーケンス（ノミナル「きほんの朝」）

| t[s] | できごと |
|---|---|
| -0.5〜0 | 静けさ。チルダウン完了、配管は極低温 |
| 0.0 | MFV開（0.3sでランプ）。タンクヘッドの水素が流れ、無点火のまま〜3,500rpmまでそっと回る |
| 0.5 | 点火器作動 |
| 0.8 | MOV 20%へ |
| 1.0 | 点火。小さな火が壁を温め始める（燃料リッチ MR≈0.6） |
| 1.5〜3.5 | ブートストラップ: 回る→流れる→温まる→もっと回る（S字加速） |
| 2.2〜2.6 | MOV 100%へ。MRが5.5へ登る |
| N>38,000 | TCVガバナがブリードを絞る（時刻でなく回転でスケジュール、実測~3.4s） |
| ~4.0 | 主段化（点火から約3秒 = タイトル回収）。pc 6.0MPa・300kN |
| 〜5.0 | 整定。吸込余裕はタンク加圧完了(4.6s)まで1.7近くの谷 |

## 簡約モデル（事前計算・集中定数系・Euler 50Hz）

状態量: N(FTP rpm), Nox(OTP rpm), Twall(壁温K), pc(室圧MPa)

- 燃料流量 mdot_f = MFV × (0.6 + 5.4·N/45000) [kg/s]（タンクヘッド分+ポンプ分）
- ジャケット出口温度 Th = 50 + (Twall−50)·w, w = 0.85/(1+mdot_f/3)
- タービン圧力比の効き pr = 0.06 + 0.94·(N/45000)^1.5（低回転では膨張比が取れない）
- タービン出力 P_t = TCV × kt × (0.15·mdot_f) × (Th−45) × pr、kt=76,000
- ポンプ所要 P_p = 7MW × (N/45000)³
- dN/dt = kN·(P_t−P_p)/(N+2000)、kN=500（定格で P_t=P_p が成立: 0.72×76000×0.9×146×1.0≈7MW）
- TCV = 1 − 0.28·ramp(N; 38000→45000)（ガバナ。時刻でなく回転でスケジュール）
- 酸素流量 mdot_o = MOV × (1.5 + 26.5·Nox/16500)（定格28kg/s → MR 5.5）、Nox は N^1.1 追従の一次遅れ(τ=0.25)
- 点火後 pc → 0.181×(0.85·mdot_f + mdot_o)×η（η: 0.6→1.0 点火後0.8sで、一次遅れτ=0.12）、推力 F = 50·pc
- 壁温: 点火前は水素で徐冷(→90K)、点火後 dTwall/dt = 1.6·((150+450·pc/(pc+0.8)) − Twall)（定格壁温≈540K）
- 酸素側吸込余裕 = NPSHa/NPSHr。NPSHa 50→75m（タンク加圧 3.0〜4.6s）、
  NPSHr = 45m×(Nox/16500)²。主段化直後に≈1.66の谷、加圧完了で1.7弱に整定

モデルは drafts/mezame/gen.ps1 で焼き、site/lab/mezame-data.js に出力（4案共通形式）。
