# 第3巻02〜09話 事実確認メモ（2026-07-27 エージェント実読検証）

## 検証済みの柱（出典つき）

- **H-II 8号機（1999-11-15）**: LE-7停止・指令破壊。約3,000mの海底からエンジンを回収し、FTPインデューサ翼の疲労破断（起点は約15µmの加工痕、旋回キャビ・入口圧振動と翼共振等の複合変動応力）と特定（Wikipedia LE-7・MHI "H-IIA Rocket Engine Development"）
- **熱力学的効果**（LH2でキャビ抑制）: NASA Lewis水素インデューサ試験（NTRS 19700008299ほか）
- **旋回キャビテーション**: LE-7液酸ポンプで超同期（約1.1×）軸振動の原因と同定し上流ケーシング変更で抑制（Kamijoら1993）。理論はTsujimoto。※現象自体の初報は1978年からあり「世界初の特定」とは書かない
- **SSME HPFTP 1976年サブシンクロナスホワール**: 数ヶ月運転制限→ロータ剛性化＋段間シールの減衰シール化で解決（Ek, NTRS 19770045710ほか）
- **ロマキン効果**: 環状シールの中心向き直接剛性（Brennen ch.10・Childs）。減衰・交差剛性は別勘定で記述
- **LE-9**: 短軸化でLE-7Aのダンパ機構を不要化／ハイブリッドセラミック軸受／オープンインペラ（IHI技報 Vol.58 No.2）
- **RL10**: タービン＋燃料ポンプ軸から歯車列で酸素ポンプ駆動（NASA TM-107318）。水素中の歯面溶着→浸炭鋼+MoS2の逸話も同資料系
- **Merlin 1D**: 単軸・両端2ポンプ・GGタービン、約36,000rpm・約1万hp（Wikipedia、出力はSpaceX公称と明記）
- **チルダウン**: RS-25ブリード予冷（NASA SLS記事）、RL10は約T-90分から予冷（TM-107318）
- **始動分類**: スピン/タンクヘッド/自己始動(ブートストラップ)を区別。LE-5系は気化水素による自己始動の実績（DLR EUCASS 2017-370）。**LE-9の始動方式名は公開資料で明言なし→書かない**
- **POGO**: ポンプ入口キャビテーションコンプライアンスが供給系の要素（NASA SP-8055）。閉ループの構成要素を列挙して記述
- **角田**: 水槽キャビテーショントンネル、回転インデューサの極低温可視化は世界初の設備（ASME JFE 2021）。LN2インデューサ試験16,500rpm（Yamada 1985）。LE-9ポンプは角田で実流体コールドフロー試験（IHI）
- **NASA 3Dプリントターボポンプ**: MSFCで液体メタン全力試験（2015-16、画像MSFC-1600485）。**LE-9のAM適用は噴射器頭部など燃焼系のみ公開確認**（MHI技報53-4）——ポンプ本体には書かない
- **27km換算**: 19.1MPa÷(71kg/m³×9.8)≈27,000m（吐出圧相当揚程と明記・入口圧の分の注記つき。液体水素密度はWikipedia/NIST）
