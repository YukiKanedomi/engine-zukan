# 目次分割の設計案（2026-07-15 下準備 → 2026-07-18 実装済み）

第2話公開のタイミングで index=目次 + episodes/ 構成へ移行する。BACKLOG の「3層データ駆動」方針の具体化。

## ファイル構成

```
site/
  index.html          目次ページ（データ駆動）
  episodes/
    01.html           第1話（現 index.html の中身を移設）
    02.html           第2話
```

- 各話は現行どおり**自己完結HTML**（CSS/JS埋め込み・ビルドなし・相対リンクのみ）を維持
- 話ページからは重複する「もくじ」ブロックを外し、表紙も小型化。もくじへは下部ページャの「← もくじ」で戻る

## 目次のデータ構造（index.html 内の JS 定数）

```js
const SHELF = [
  { vol:"第1巻 ロケット編", episodes:[
    { no:"01", title:"ロケットは、すてながら とんでいく", href:"episodes/01.html", status:"up" },
    { no:"02", title:"うしろに投げると、まえにすすむ",     href:"episodes/02.html", status:"up" },
    { no:"03", title:"燃料のえらびかた — 固体と液体",     status:"soon" },
    // ...
  ]},
  { vol:"読み切り（EX）", episodes:[] },   // 自由枠。増えたらここに1行足すだけ
  // 第2巻 飛行機編 も将来ここに1ブロック追加
];
```

- 3層 = 巻（SHELF の要素）→ 話（episodes）→ 読み切り（EX 巻として表現）
- 拡張は「データ1行」: EX話追加・巻追加・章立て組み替えすべて SHELF の編集だけで済む

## 既読管理（検討中 → 最小案）

- 各話ページの末尾で `localStorage.setItem("read:01", 1)` を打つだけ
- 目次側は該当キーがあれば「よんだ ✓」タグを表示
- サーバ不要・ビルド不要で現方針と両立。プライベートな読書記録なので localStorage で十分

## 移行時の注意

- 移行後、ルート URL（現・第1話）は目次に変わる。共有済みリンクは目次に着地するだけなので実害なし
- viz-panels 掲載分（第1話コピー）はそのまま。以降の連載は本体 Pages のみ
- ページャの「← もくじ」は `../index.html`、話間は `01.html`↔`02.html` の相対リンク

## アイコン（2026-07-15 追加）

- site/ 直下にアイコン一式あり（favicon.svg マスター＋各サイズPNG/ico/manifest）。index.html の head にリンク済み
- **episodes/ 配下の話ページに入れるときは href を `../favicon.ico` 等に読み替える**こと（相対パス運用のため）
