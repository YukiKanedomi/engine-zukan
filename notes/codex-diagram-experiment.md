# 実験記録: Codex往復による技術図解の生成（2026-07-17）

「生成AI画像は構造が不正確になるため図解に不使用」の方針を、検品ループ前提で再検証した。

## 実験

題材: ガス発生器サイクルの系統図（配管トポロジーに客観的な正解がある）

- **Round 1**: 英語の詳細プロンプトで生成。結果、配管トポロジーは9割正解
  （タンク→ポンプ→主流が燃焼室、両ポンプ出口から分岐→ガス発生器→タービン、排気は機外投棄、色分け一貫）。
  誤り1点: タービンが軸に乗っておらず「ポンプを回す」構造になっていない。
  ※Codex自身もログ内で同じ誤りに気づいていた（自己検品能力あり）
- **Round 2**: 誤り1点だけを名指しで修正指示（他は維持と明記）。
  → 修正が正しく入り、他の配管・スタイルは壊れなかった。**2往復で正解に収束**

画像: scratchpad/diagram-exp/round1.png, round2.png（一時領域。採用時は要保全）

## 結論

**「系統図・ブロック線図クラスは、検品ループ前提なら実用域」**。ただし本図鑑での使い分けは:

| 図の種類 | 手段 | 理由 |
|---|---|---|
| 本編の解剖図（タップ切替） | SVG自作（現行維持） | タップで部位をハイライト/dimする対話が**ラスタでは不可能**。日本語ラベルも生成では不安定 |
| サイクル線図・グラフ | SVG自作（現行維持） | 数値の正確さが必要 |
| よりみち等の静的な挿図・実機カタログの雰囲気カット | Codex往復も可 | 正確さは検品ループで担保できる。ただし夫の技術検収を通すこと |
| SVG自作の下絵・構図の参考 | Codex歓迎 | 正確さ・対話性・スタイル統一はSVG側で担保しつつ、構図の味だけ借りる |

## 検品ループの手順（採用する場合の型）

1. プロンプトは**トポロジーを文章で完全指定**（何と何が繋がる/繋がらない、NOT も明記）。ラベルは英語
2. Claudeが生成画像を目視検品（結線・矢印・部品の有無を一次資料と照合）
3. 誤りは**1点ずつ名指し**で修正発注。「他は維持」を必ず明記
4. 収束後、夫の技術検収 → 採用
5. 注意: 毎回の編集は再サンプルなので、修正のたびに**全体を再検品**する（直った箇所以外の退行がないか）

## 追試: ターボポンプ断面図（2026-07-17・解剖図クラス）

系統図より難しい「形そのものの正確さ」を試した。単軸ターボポンプの断面
（吸込→インデューサ→遠心羽根車→ボリュート→軸受×2→シール→タービン）。

- **Round 1**: 全体配置・ダクト・ボリュートの巻きは正解。誤り3点:
  ①タービンロータが螺旋ねじ ②羽根車まわりの矢印が一部逆流 ③羽根車左側の軸受欠落（ラベルが宙を指す）
- **Round 2**: 3点を名指し同時修正（「他は維持」明記）→ **3点とも修正され退行なし。2往復で収束**

学び:
- 複数点の同時修正指示も通る（1点ずつでなくてよい）
- 断面図は「厳密な子午面断面」ではなく「様式化されたカットモデル」として出てくる。
  図鑑用途では問題ないが、教科書的な断面の約束事を求めるなら別途指示が要る
- ラベルの指し先（引出線が実在部品を指すか）も検品項目に入れること

## 追試2: やさしい絵柄への着せ替え（2026-07-17・Round 3）

構造が収束した round2 を参照させ、絵柄だけを図鑑パレット
（クリーム地 #fdf9f0／砂 #f6d9b8／水色 #9cc0d4／テラコッタ #c47a4f／墨紺 #3a4550、
ハッチングなし・フラット塗り・ゆる線）に変更指示 → **構造を完全維持したまま着せ替え成功**。

結論: 「①技術画風で構造を収束させる → ②絵柄を着せ替える」の2段パイプラインが成立する。
正確さ×やさしい絵柄の両立は本図鑑の独自価値になり得る（教科書図とかわいいイラストの間の空白地帯）。
画像は drafts/turbopump-exp/ に保全済み（round1〜3）。

## 追試3: ゆるかわ3D断面カットモデル（2026-07-17・ロケット全体）

生成AIの得意分野（立体表現）×ゆるかわ絵柄を一発指定で試した。二段式液体ロケットの3/4視点カットモデル。

- **Round 1**: ほぼ一発正解。段の順序・段間部内の真空エンジン・LOXフィードパイプの取り回し・
  エンジンクラスタ・ラベル指し先まで全部正しい。点目の衛星もかわいい。
  誤り1点のみ: 尾部にフィン（現代の液体ロケットには無い）
- **Round 2**: フィン除去のみ指示 → 完了、退行なし。**2往復で完成**

学び: 立体カットモデルは最初からゆるかわ指定でも構造が崩れない（2段パイプライン不要のケースもある）。
平面断面図（ターボポンプ）より3D構造のほうがむしろ得意な様子。
画像は drafts/rocket3d-exp/ に保全。第1話のよりみち挿図・目次のヒーロー画像・PDF製本の表紙などに転用候補。

## 未検証・既知の限界

- 日本語ラベル（文字化けリスク高。図中は英語にして HTML 側で日本語を添えるのが安全）
- 3往復以上での収束性（今回の2往復は好条件だった可能性。修正が別の退行を生む場合がある）
- 複数の図をまたぐスタイル統一（連載9話分をそろえるのはSVGのほうが確実）
